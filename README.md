# Landing Page de Portafolio Personal - Pablo

Este proyecto es mi primera Landing Page (Portafolio Personal) desarrollada para la Práctica Formativa Obligatoria 1 (PFO 1). He decidido aplicar una estética "Retro / Legacy" inspirada en sistemas operativos de los años 90 y terminales antiguas, haciendo un guiño a mis raíces en Visual Basic y mi experiencia laboral actual manteniendo sistemas lógicos en Visual FoxPro.

- [x] Se ha organizado el layout (especialmente en la sección "tarjetas") utilizando Flexbox o Grid.
- [x] **Redacta: ¿Qué ventajas encontraste al utilizar Flexbox o Grid en tu proyecto?**
  *Respuesta:* Flexbox me permitió aplicar la propiedad `display: flex` combinada con `flex-wrap: wrap` al contenedor de los proyectos. La gran ventaja es que las tarjetas se alinean en columnas automáticamente y, al reducir el tamaño de la ventana, bajan al siguiente renglón de forma fluida sin necesidad de escribir código complejo para pantallas móviles.

**Estilización de Componentes:**

- [x] Se ha implementado al menos una animación o transición.
- [x] **Redacta: ¿Qué animación o transición implementaste y por qué consideraste que era adecuada para tu proyecto?**
  *Respuesta:* Implementé la pseudo-clase `:hover` junto a una transición (`transform: translateY(-8px)`) sobre las tarjetas de los proyectos. Consideré que era adecuada porque brinda feedback de interactividad visual instantáneo sin romper con el estilo rígido y pixelado del sistema retro. Además, usé bordes `inset` y `outset` para simular el hundimiento físico de los botones antiguos.
